--- B. Realistic novelty rate (new metric) ---

Read meta.generated_dir from each published diversity_report.json and use
exactly those directories - do not guess which generated set backed the
published numbers:

  results/sharp1/eval1600/diversity/diversity_report.json  -> <SHARP1_DIR>
  results/mirror2/eval/diversity/diversity_report.json     -> <MIRROR2_DIR>

Then:

  python metrics/novelty_rate.py --real data/source/images \
      --generated <SHARP1_DIR>  --out results/sharp1/eval1600/novelty
  python metrics/novelty_rate.py --real data/source/images \
      --generated <MIRROR2_DIR> --out results/mirror2/eval/novelty

  # full-scale calibration check (disjoint real halves; expect ~5%):

      --generated data/source/images --calibration-check \
      --out results/_probes/novelty_calibration

novel_examples/ folder pairing the most novel realistic frames with their
nearest catalogue frame. Include the novel_examples folders in the
sync-back - they are article figure material.

meta.generated_dir the same way, out to results/rebalance4/eval/novelty)
